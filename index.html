🌐 Utiliser l'application sur Smartphone

Pour faire l'appel et noter la participation en vous baladant dans la classe avec votre téléphone, voici la méthode pour héberger ce fichier gratuitement :

Étape 1 : GitHub (Gratuit)

  1. Allez sur github.com depuis votre PC et créez un compte.
  2. Créez un nouveau "Repository" (dépôt public). Nommez-le carnet-svt.
  3. Cochez "Add a README file" puis validez.
  4. Dans votre dépôt, cliquez sur Add file > Upload files. Sélectionnez le fichier HTML que vous êtes en train d'utiliser. Renommez-le index.html.
  5. Cliquez sur "Commit changes".

Étape 2 : Activer le lien web

  1. Toujours dans GitHub, allez dans l'onglet Settings (Paramètres du dépôt).
  2. Dans le menu gauche, cliquez sur Pages.
  3. Sous "Build and deployment / Branch", choisissez main et cliquez sur Save.
  4. Patientez 2 minutes. Un lien web va s'afficher en haut : https://[votre-pseudo].github.io/carnet-svt/
🚀 C'est prêt ! Ouvrez ce lien sur votre téléphone. Ajoutez la page à votre écran d'accueil. L'appli fonctionnera comme une vraie application !

⚠️ Attention : Le site ne sauvegarde les notes QUE sur l'appareil utilisé. Pensez à faire "Save Backup" sur votre PC, vous envoyer le fichier .json généré par email/whatsapp, puis l'ouvrir sur le téléphone via "Load Backup" pour synchroniser.
